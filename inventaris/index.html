Koneksi Sistem

Masukkan URL Google Sheets (untuk baca data) dan URL Google Apps Script (opsional, untuk upload foto otomatis). Lihat halaman Panduan untuk cara lengkapnya.

Panduan Penggunaan

1

Siapkan Google Sheet

Buat Google Sheet baru dengan kolom header di baris pertama:

NO | NAMA BARANG | NO INVENTARIS | KATEGORI | MERK/TYPE | TAHUN PEROLEHAN | JUMLAH | HARGA SATUAN | KONDISI | LOKASI | DOKUMENTASI | KETERANGAN

Isi data barang mulai baris kedua.

2

Publish Google Sheet

  1. Buka Google Sheet Anda
  2. Klik menu File → Share → Publish to web
  3. Pada bagian format, pilih Comma-separated values (.csv)
  4. Klik tombol Publish
  5. Copy link yang muncul
3

Hubungkan ke Dashboard

  1. Buka halaman Pengaturan di aplikasi ini
  2. Paste link yang tadi di-copy ke kolom URL
  3. Klik Hubungkan
  4. Data akan otomatis tampil di Dashboard!
4

Menambah Foto Barang

Ada 2 cara menambah foto:

📱 Cara 1: Upload Otomatis (Google Apps Script)

  1. Pastikan URL Google Apps Script sudah diisi di Pengaturan.
  2. Klik tombol 📷 di kolom Aksi barang.
  3. Pilih Ambil Foto atau Pilih dari Galeri, lalu masukkan password Admin.
  4. Tunggu proses loading. Foto akan otomatis masuk ke Google Drive & tautannya tersimpan di Google Sheet!

🔗 Cara 2: Dari Google Drive

  1. Upload foto ke Google Drive
  2. Klik kanan foto → Share → ubah ke Anyone with the link
  3. Copy link-nya
  4. Paste link ke kolom DOKUMENTASI di Google Sheet
5

Update Data

Cukup edit data langsung di Google Sheet. Dashboard akan otomatis terupdate sesuai interval refresh yang dipilih (default: 5 menit). Anda juga bisa klik tombol 🔄 Refresh untuk update manual.
